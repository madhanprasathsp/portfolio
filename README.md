# Madhanprasath S — Portfolio

React + Vite single-page portfolio.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static output in dist/
```

All content lives in `src/data/resume.js`. Update the LinkedIn and GitHub URLs there.
The downloadable résumé is `public/Madhanprasath_S_Resume.pdf`.

Deploy `dist/` to any static host (Vercel, Netlify, GitHub Pages).
